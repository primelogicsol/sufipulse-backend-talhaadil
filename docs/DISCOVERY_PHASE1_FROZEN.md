# SufiPulse Traditional Search Discovery — Phase 1 (Frozen)

Scope is limited to YouTube / SufiPulse USA and SufiPulse.com until the phase is proven.

Backend work should support a single master release identity, published catalogue reads for server rendering, canonical song metadata, stable YouTube video IDs, thumbnail URLs, writer/composer attribution, lyrics/context, alternate titles/languages, and machine-readable feed/sitemap generation. Do not add SSC, DKF, Facebook, or other properties in this phase.
